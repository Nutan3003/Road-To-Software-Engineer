# Day 1 - Introduction to Prompt Engineering

## What is Prompt Engineering?

Prompt Engineering is the process of creating clear and effective instructions (prompts) for AI systems to get accurate and useful outputs.

A prompt can be a question, command, or set of instructions given to an AI tool such as ChatGPT, Gemini, or Claude.

## Why is Prompt Engineering Important?

In today's AI-driven world, the quality of the output depends on the quality of the prompt.

A well-written prompt helps:
- Generate accurate responses
- Save time
- Improve productivity
- Get structured outputs
- Reduce errors and misunderstandings

## Example

### Basic Prompt
```
Write a resume.
```

### Better Prompt
```
Act as a professional resume writer.
Create an ATS-friendly resume for a Java Developer with skills in Java, SQL, Spring Boot, and React.
```

The second prompt provides more context and produces a better result.

## Key Takeaways

- Prompt Engineering is the skill of communicating effectively with AI.
- Better prompts lead to better outputs.
- It is becoming an essential skill for Software Engineers in the AI era.
