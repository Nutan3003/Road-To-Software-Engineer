# Day 11 - Prompt Templates and Reusable Prompts

## Today's Learning

Today, I learned about Prompt Templates and how they help create consistent and reusable prompts.

Instead of writing a new prompt every time, we can create a template with placeholders and fill in the required information whenever needed.

---

## What is a Prompt Template?

A Prompt Template is a predefined structure that contains placeholders for dynamic information.

It helps save time, maintain consistency, and generate better AI responses.

---

## Why Use Prompt Templates?

Prompt Templates help to:

- Save time by reusing prompts.
- Maintain consistency across different tasks.
- Improve the quality of AI responses.
- Reduce the chances of missing important details.
- Increase productivity.

---

## General Template

```
Act as a [ROLE].

Your task is to [TASK].

Context:
[BACKGROUND INFORMATION]

Requirements:
- [Requirement 1]
- [Requirement 2]
- [Requirement 3]

Provide the output in [FORMAT].
```

---

## Example 1 - Interview Preparation

```
Act as a Software Engineering interviewer.

Ask me 5 Java interview questions.

Requirements:
- Start with easy questions.
- Increase the difficulty gradually.
- Explain the correct answer after each question.
```

---

## Example 2 - Resume Review

```
Act as an ATS Resume Reviewer.

Review my resume for a Software Engineer role.

Provide:
- ATS Score
- Strengths
- Weaknesses
- Suggested Improvements
```

---

## Example 3 - Learning a Topic

```
Act as an experienced teacher.

Explain Operating System Scheduling.

Include:
- Definition
- Types
- Real-world example
- Interview questions
- Summary
```

---

## Benefits of Prompt Templates

- Reusable for similar tasks.
- Easy to customize.
- Produces structured outputs.
- Saves time.
- Improves prompt quality.

---

## Applications in Software Engineering

Prompt Templates can be used for:

- Learning new technologies
- Resume reviews
- Code generation
- Debugging
- Interview preparation
- Project documentation
- Writing emails
- Creating technical notes

---

## Key Takeaways

- Prompt Templates make prompts reusable.
- They improve consistency and productivity.
- Small changes in placeholders can adapt the same template for different tasks.

---

## Reflection

Today, I realized that Prompt Templates make interacting with AI much more efficient. Instead of writing prompts from scratch every time, I can reuse a structured template and simply modify the role, task, or context based on my needs.
