## Difference Between Google and ChatGPT

| Google | ChatGPT |
|----------|----------|
| Searches information from websites | Generates responses using AI |
| Provides links to resources | Provides direct answers |
| User needs to read multiple sources | Information is summarized in one response |
| Best for finding information | Best for understanding and creating content |



## Types of Prompts I Explored

- Basic Prompt
- Role-Based Prompt
- Instruction Prompt
- Question Prompt

## Example

### Basic Prompt
```

```

### Role-Based Prompt

