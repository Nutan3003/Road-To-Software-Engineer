# Day 4 - Role Prompting (Persona Prompting)

## Today's Learning

Today, I learned about Role Prompting, one of the most useful Prompt Engineering techniques.

Role Prompting means assigning a specific role or persona to the AI before asking a question.

By defining a role, the AI can generate more focused, relevant, and structured responses.

---

## What is Role Prompting?

In Role Prompting, we tell the AI who it should act as before performing a task.

Examples of roles:

- Software Engineer
- Java Instructor
- Resume Reviewer
- Interviewer
- Career Mentor
- System Design Expert

---

## Example 1

### Basic Prompt

```
Explain Java Collections Framework.
```

### Role Prompt

```
Act as an experienced Java instructor and explain the Java Collections Framework with simple examples.
```

The second prompt provides more context and usually produces a clearer response.

---

## Example 2

```
Act as a technical interviewer and ask me five Java interview questions.
```

---

## Benefits of Role Prompting

- Produces more focused responses.
- Improves response quality.
- Generates outputs in a specific style.
- Useful for learning, interview preparation, and content creation.

---

## Key Takeaways

- Role Prompting assigns a persona to the AI.
- Providing context improves output quality.
- Different roles can produce different perspectives for the same problem.

---

## Reflection

Today, I learned that giving AI a specific role helps generate more relevant and high-quality responses. This technique can be very useful for interview preparation, learning new concepts, and solving problems from different perspectives.
